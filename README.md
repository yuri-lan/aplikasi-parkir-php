# Aplikasi Sistem Parkir
Aplikasi manajemen parkir dengan PHP Native, PDO, dan MySQL.

## Akun Demo
- Admin: admin1 / admin123
- Petugas: petugas1 / petugas123
- Owner: owner1 / owner123

## Cara Install
1. Import file `db_parkir.sql` ke phpMyAdmin.
2. Letakkan folder di `htdocs`.
3. Buka `localhost/parkir_app`."# aplikasi-parkir-php"
